## Descripción

Este proyecto consiste en el diseño de una interfáz de usuario web para la plataforma de cine "Cine Aurora".
Cine Aurora es una plataforma web de cine donde los usuarios pueden visualizar películas en cartelera, ver detalles de cada film, explorar próximos estrenos y gestionar su perfil.

El objetivo del proyecto es aplicar conocimientos de **HTML, CSS (Flexbox y Grid), diseño responsivo y trabajo colaborativo con Git y GitHub**.

## Tecnologías y técnicas utilizadas

Para este proyecto se utilizarán **HTML** y **CSS** y aplicando, con el fin de la evaluación:

- Flexbox
- Grids
- Media queries
- Modularización CSS

---

## Funcionalidades

* Visualización de películas en cartelera
* Diseño responsive (adaptado a celular y desktop)
* Navegación entre páginas
* Vista detallada de películas
* Formularios de login y registro
* Sección de próximos estrenos

---

## Diseño

* Uso de paleta de colores personalizada mediante variables CSS
* Aplicación de Flexbox y Grid para layout
* Efectos visuales con hover y transiciones
* Uso de la regla de los 4px para espaciados

---

## Responsive

El sitio fue adaptado mediante **media queries** para garantizar una correcta visualización en dispositivos móviles.
